## Contributing

This project was built solo for the **0G APAC Hackathon 2026**. Post-hackathon contributions are welcome.

### How to Contribute

```
1. Fork  →  2. Branch  →  3. Code  →  4. Test  →  5. PR
```

```bash
# 1. Fork on GitHub, then clone your fork
git clone https://github.com/<your-username>/SmartChain-Hub.git

# 2. Create a feature branch
git checkout -b feat/your-feature

# 3. Follow existing patterns (TypeScript strict, Solidity 0.8.20, Python 3.12)

# 4. Run all tests before opening a PR
npm test                          # Frontend (Jest)
pytest ai-agent/tests/            # AI Agent (pytest)
npx hardhat test                  # Contracts (Hardhat)

# 5. Open a PR with: what changed, why, and how to test it
```

### Development Setup

```bash
git clone https://github.com/mokwathedeveloper/SmartChain-Hub.git
cd SmartChain-Hub

# Frontend — Next.js 16
cd smartchain_hub_frontend
cp .env.local.example .env.local   # fill in keys
npm install && npm run dev          # http://localhost:3000

# AI Agent — Flask + TensorFlow
cd ../ai-agent
cp .env.example .env               # set OG_COMPUTE_PRIVATE_KEY
pip install -r requirements.txt
python3 server/app.py              # http://localhost:5000

# Smart Contracts — Hardhat
cd ../blockchain
cp .env.example .env               # set PRIVATE_KEY
npm install
npx hardhat test
```

See [README.md](README.md) for the full environment variable reference.
