## THE DEMO FLOW — 7 STEPS

---

### STEP 1 — Landing Page *(20 seconds)*

**What to click:** Open `smartchainhubfrontend.vercel.app`

**What to say:**
> "This is SmartChain Hub. A live, running platform —
> not a mockup, not a concept.
> Built on 0G Galileo Testnet. Let me show you what it does."

**What to point at:**
- The hero headline — "The first sovereign AI agent economy"
- The navigation bar — show there are real pages (Dashboard, Transactions, Revenue, Console)
- The 0G Galileo Testnet badge if visible

**Do NOT linger.** Navigate immediately to Transactions.

---

### STEP 2 — Transactions Page: Enable Demo Mode *(20 seconds)*

**What to click:** `Transactions` in the sidebar → toggle **Demo Mode ON**

**What to say:**
> "Demo Mode means you don't need a wallet to see the full AI flow.
> Every result is real — real AI inference, real proof generation.
> Only the on-chain write is simulated."

**What to point at:**
- The Demo Mode toggle — show it turning on
- The three tabs: **Optimize · History · Analytics**
- The priority selector: **Efficiency / Speed / Balanced**

---

### STEP 3 — Run the AI Optimization *(45 seconds)*  ← THIS IS THE CORE

**What to click:**
1. Enter an amount — type **`500`**
2. Set priority to **Efficiency**
3. Click **Optimize Transaction**
4. Wait for the result (5–10 seconds)

**While it is loading, say:**
> "Right now, 0G Compute TeeML is running LLaMA 3.1 8B
> inside a Trusted Execution Environment.
> The model is analyzing the optimal fee, route, and savings —
> and generating a cryptographic proof that it ran correctly."

**When the result appears, point at each field and say:**

- **Optimal Fee** →
  > "This is the AI-recommended fee — not a guess. Proven."

- **Route** →
  > "Best routing path — selected from live network conditions."

- **Savings** →
  > "This is how much the user saves versus a standard transaction."

- **TEE Proof / ZK Commitment** →
  > "This SHA-256 hash is the cryptographic commitment.
  > It proves the AI ran correctly, the savings are real,
  > and the fee is under 2%.
  > Not a claim. A fact — anchored on-chain."

- **Confirm / Save the transaction** →
  Click to save it. Watch the success state appear.

  > "That transaction is now written to 0G Storage Log
  > as an immutable Merkle root receipt.
  > The agent's reputation just updated on-chain."

## If Something Goes Wrong

| Problem | Recovery |
|---|---|
| AI optimization is slow / times out | Say: "TeeML broker is processing — meanwhile let me show you what the result looks like." Open Dashboard to show a previous result. |
| Wallet not connecting | Say: "Demo Mode handles this — no wallet needed." Toggle Demo Mode on. |
| Page not loading | Have a screen recording of the demo as a backup. Open it immediately. |
| Console shows no logs | Reload the page. Logs start within 3 seconds of page load. |
| 0G Explorer is slow | Have the contract page pre-loaded in the tab before you start. |

## Pre-Demo Checklist (Do This 10 Minutes Before)

- [ ] Log in to the platform — do not demo the auth flow
- [ ] Navigate to Transactions — confirm Demo Mode toggle is visible
- [ ] Run one test optimization — confirm the result renders correctly
- [ ] Open Dashboard — confirm stats and activity are loading
- [ ] Open Console — confirm logs are streaming
- [ ] Open Revenue — confirm the donut chart and pending earnings load
- [ ] Open 0G Explorer in a second tab — paste AgentID contract address and pre-load it
- [ ] Turn off browser notifications
- [ ] Close all other tabs except these two
- [ ] Set screen brightness to maximum
- [ ] Zoom browser to 110% — makes everything more readable on a projected screen
