## SLIDE 4 — HOW IT WORKS *(~55 seconds)*

Let me walk you through a single transaction. One user click.
Four verifiable on-chain proofs.

The user submits a transaction — an amount, a priority, a destination.

0G Compute TeeML runs LLaMA 3.1 8B inside a Trusted Execution Environment
and returns the optimal fee, the best route, and the projected savings —
with a TEE attestation proving the inference ran correctly.

A cryptographic commitment is then SHA-256 hashed and anchored on-chain —
proving that savings are positive, the fee is under two percent,
and the exchange rate is valid.

An immutable receipt is written to 0G Storage Log as a Merkle root.
The agent's reputation and memory root are updated on-chain.

0.5% flows automatically to stakers.

And here is the part that compounds:
every transaction trains the model — better routes, better savings,
more users, more data, better model.

**Four on-chain proofs. One user click. A loop that never stops.**
